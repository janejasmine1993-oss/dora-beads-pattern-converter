# Known Issues

## v0.3.1 当前已知问题

- **色卡为示例数据**（各品牌 20 个基础色），无法代表真实 MARD/COCO/漫漫/盼盼/咪小窝 色号。
  真实颜色还原需要接入完整品牌色卡（如 Mard221），计划在 v0.4.0 实现。
- PDF 导出未实现（按钮显示"待开发"）。
- Excel / CSV 导出未实现（按钮显示"待开发"）。
- 自动去背景功能只预留接口，未接入真实 API。
- AI 风格化功能只预留接口，未接入真实 API。
- 小图改大（AI 超分）功能只预留接口，未接入真实 API。
- 颜色量化（`quantize.ts`）未实现，复杂图片的色号种数可能较多。
- 大尺寸（如 256×256 以上）生成可能有轻微卡顿（主线程同步计算）。
- `mergeColors.ts` 合并相近色功能未实现。
- 半透明边缘像素（alpha 在 32-200 之间）目前按非透明处理，颜色受 premultiplied alpha 影响可能偏暗。
