# Known Issues

## v0.4.0 当前已知问题

### 已完成（v0.4.0）
- ✅ 裁剪、旋转/翻转预处理
- ✅ 画笔/橡皮/填充/删除填充/选区/颜色替换/删除某色/描边/撤销/重做/快速色板

### 待实现（P1，v0.4.x）
- ⬜ **一键去背景**：AI 背景抠图未实现，接口已预留位置
- ⬜ **填充 Delta-E 阈值**：当前填充为精确同色码匹配；Lab 距离阈值填充可后续加入
- ⬜ **项目状态本地保存**：页面刷新后编辑结果丢失；localStorage/IndexedDB 方案待实现
- ⬜ **大格子图拖拽性能**：128×128 在 4× 缩放时画布 >4000px，快速拖拽可能有轻微延迟
- ⬜ **画笔大小 2×2/3×3**：当前只支持 1×1，多格画笔可后续加入

### 待解决问题

- **色卡授权待确认**：当前色卡数据来源为开源社区项目（mumu-0922/pindou，license="community"，Zippland/perler-beads 使用 AGPL v3），仅用于开发测试，商用前需确认授权或自行整理品牌官方数据。
- **颜色名称待完善**：当前 name 字段与 code 相同（如 "A01"），未接入官方中文颜色名（如"象牙白"）。
- **半透明边缘像素**：alpha 在 32-200 之间的边缘像素按非透明处理，颜色可能受 premultiplied alpha 影响略偏暗。
- **大尺寸生成卡顿**：256×256 以上在主线程同步计算可能有轻微卡顿。
- **PDF 导出**：未实现（按钮显示"待开发"）。
- **Excel / CSV 导出**：未实现（按钮显示"待开发"）。
- **自动去背景 / AI 风格化 / AI 超分**：只预留接口，未接入真实 API。
