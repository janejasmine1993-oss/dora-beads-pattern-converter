# 小程序开发路线图

## 为什么做小程序？

### 市场驱动

1. **用户习惯**：相比 Web 应用，小程序的留存率高 3-5 倍
2. **商业化前置**：小程序支持原生支付（微信支付），可提前变现
3. **推荐机制**：微信生态推荐算法倾向本地应用，流量获取成本低
4. **社交属性**：小程序原生分享功能，自带传播力
5. **用户基数**：微信 10 亿日活，潜在客户海量

### 产品驱动

1. **低门槛使用**：不需要下载 App，即用即走
2. **会员转化**：小程序内置支付，转化链路短
3. **内容分发**：易于在微信生态分享作品
4. **离线能力**：可预加载常用功能和色卡
5. **消息推送**：用户接收任务完成通知

## 小程序 MVP 范围

### 第一阶段：核心生成流程（v0.7.0）

#### 功能

1. **用户登录**
   - 微信登录（一键登录）
   - 访客模式（部分功能限制）

2. **图片上传与处理**
   - 拍照 / 从相册选择
   - 图片裁剪
   - 本地基础预处理（支持旋转、翻转）

3. **AI 优化**（可选的预处理步骤）
   - AI 去背景（调用腾讯云）
   - 风格转换（可选，需扣费）

4. **参数选择**
   - 品牌品选择（MARD / PERLER / 其他）
   - 尺寸选择（预设或自定义，最大 128×128）
   - 颜色数量限制

5. **图纸预览与生成**
   - 实时预览（缩小尺寸显示）
   - 一键生成
   - 进度条反馈

6. **导出与保存**
   - 导出高清 PNG（微信直接分享）
   - 保存到历史记录
   - 分享到微信群 / 朋友圈

7. **会员系统**
   - 显示当前等级和剩余 AI 次数
   - 购买 / 兑换会员入口
   - 购买 AI 次数包

8. **历史记录**
   - 列表展示最近的图纸
   - 支持删除
   - 支持重新编辑

## 小程序第一版不做

❌ 复杂图纸编辑器（>10 个编辑工具）
❌ 选区功能（包括魔棒、矩形、自由选择）
❌ 键盘快捷键
❌ 大型专业 PNG 模板（格子线、色号标注、水印等）
❌ 已有图纸 OCR 识别
❌ 复杂像素图校准（手动参数太多）
❌ PDF / SVG / Excel 导出
❌ 图纸版本管理
❌ 协作编辑

## 开发计划

### 时间线

```
v0.7.0 前：完成抽象层设计和数据模型 ✅（v0.5.4）
v0.7.0 - v0.7.1：云服务接入和会员系统
v0.7.1 - v0.8.0：小程序 MVP 开发
v0.8.0：上线腾讯云 + 小程序二合一
```

### 开发量估算

- **前端小程序代码**：800 - 1000 行
- **服务接口适配**：400 - 500 行
- **测试**：300 - 400 行
- **总工时**：4 - 6 周（1 名全栈工程师）

## 审核与发布

### 腾讯云小程序上线要求

1. **主体信息**
   - 公司营业执照
   - 法人身份证
   - 小程序名称审核

2. **服务条款**
   - 《用户服务协议》
   - 《隐私政策》
   - 《使用规范》

3. **安全审核**
   - 无色情、暴力、违法内容
   - 无恶意扣费
   - 无诱导分享

4. **功能审核**
   - 支付必须真实对应商品 / 服务
   - AI 生成内容标注
   - 用户数据存储符合法规

5. **上线检查清单**
   - [ ] 隐私政策完整
   - [ ] 用户协议完整
   - [ ] 无虚假宣传
   - [ ] 无诱导消费
   - [ ] 错误提示清晰
   - [ ] 支付流程完整
   - [ ] 云服务备案完成

### 版本迭代策略

1. **灰度发布**：先 10% 用户，观察 1 周后全量
2. **灰度回滚**：发现严重问题立即 rollback
3. **小版本更新**：周更（bug fix + 小功能）
4. **大版本更新**：月更（重大功能或重构）

## 商业化前提

小程序上线前必须完成：

- [ ] Web 端会员系统成熟且有用户转化
- [ ] 腾讯云数据库和存储正式上线
- [ ] 微信支付和兑换码流程验证完成
- [ ] 云迁移完成（国内数据存储）
- [ ] 法务完成合规审查
- [ ] 内测用户反馈收集（最少 100 人）

## 小程序主体注册

### 腾讯云小程序注册流程

1. 注册企业微信公众号平台账号
2. 创建小程序（绑定已有公众号或新建）
3. 填写小程序信息和服务类目
4. 上传营业执照和法人身份证
5. 等待腾讯审核（3-5 天）
6. 配置开发者密钥
7. 下载开发工具
