# 导出规范

## 文件命名规则（v0.3.4 起）

```
哆啦拼豆图纸_图纸名_[镜像]_品牌名_宽x高_日期.扩展名
```

示例：

```
哆啦拼豆图纸_天王星_MARD_52x52_2026-06-04.png
哆啦拼豆图纸_天王星_镜像_MARD_52x52_2026-06-04.png
哆啦拼豆图纸_MARD_104x104_2026-06-04.png          （未填图纸名时省略）
```

规则：
- 图纸名取自用户输入或上传文件名（去扩展名）；未填时省略
- 特殊字符（`\/:*?"<>|`）自动过滤；最长 30 字符
- 开启镜像时在品牌名前加 `_镜像`

## 专业 PNG 版式规范（v0.3.4 起）

### 标题栏（顶部）

| 位置 | 内容 | 说明 |
|------|------|------|
| 左上第 1 行 | `哆啦拼豆图纸` | 固定品牌文案，bold，16px |
| 左上第 2 行 | 色卡系列名（如 `Mard221`） | 12px，副标色 |
| 右上第 1 行 | 图纸名称（含镜像标记） | bold，18px；开启镜像时追加 `[镜像]` |
| 右上第 2 行 | 图纸尺寸 / 主体尺寸 | 11px，灰色 |

### 镜像功能规范

- 页面导出面板提供"左右镜像"开关（默认关闭）
- 开启后，专业 PNG 和简洁 PNG 的图案格子均左右翻转（`mirroredCol = width - 1 - col`）
- **以下内容不得被镜像翻转，必须保持正常可读方向：**
  - 格子内品牌色号文字
  - 顶部品牌文案与色卡系列名
  - 顶部图纸名称
  - 四周坐标标尺数字
  - 底部色号图例文字
  - 底部统计信息
  - 水印文字
- 开启镜像时，专业 PNG 标题右侧自动追加 `[镜像]`，文件名包含 `_镜像`
- 豆量统计、色号种数在镜像前后不变

### 水印

| 类型 | 位置 | 内容 | 样式 |
|------|------|------|------|
| 斜向水印 | 格子区背景 | `哆啦拼豆图纸`，-30° | `globalAlpha=0.055`，13px bold，clipped 到格子范围 |
| 水印条 | 底部水印条右侧 | `哆啦拼豆图纸 · 日期` | 80% 透明度，11px bold，酒红色 |

### 网格线层级（v0.3.6 起）

| 类型 | 颜色 | 线宽 | 说明 |
|------|------|------|------|
| 普通细网格 | `rgba(0,0,0,0.10)` | 0.5px | 最细，覆盖含透明区全部格子 |
| 每 10 格粗线 | `rgba(30,30,30,0.32)` | 1.6px | 中性深灰，明显分区 |
| 外边框 | `#8A1538`（酒红） | 2px | 最明显，酒红色 |

### 透明区域

- 透明格子不填充颜色，显示白色背景
- 细网格线覆盖透明区和非透明区，统一绘制
- 透明区内 10 格粗线和外边框同样可见

### 四周坐标标尺

- 背景色：`#fff0f2`（极浅玫瑰）
- 边框色：`rgba(138,21,56,0.28)`（酒红半透明）
- 数字颜色：`#8A1538`（深酒红）
- 主要刻度（10 倍数、首格、末格）加粗

### 字体栈

专业 PNG 所有文字区域统一使用：

```
"PingFang SC", "Microsoft YaHei", "Noto Sans SC", "Helvetica Neue", Arial, sans-serif
```

格子内品牌色号标注使用等宽字体：

```
"SF Mono", Menlo, Consolas, "Courier New", monospace
```

不引入额外字体文件，全部使用系统字体 fallback。

## PNG 导出规则（通用）

- 导出图纸预览图（格子图或色号图）
- **导出倍率：`EXPORT_SCALE = 2`**（v0.3.5 起），物理 Canvas 为逻辑尺寸的 2 倍
- 逻辑分辨率：每格按尺寸自适应（最小 10px，最大 28px）
- 物理分辨率：逻辑值 × 2，放大查看格子内色号文字清晰
- 包含网格线
- 包含水印条
- 使用 `Canvas.toDataURL('image/png')`
