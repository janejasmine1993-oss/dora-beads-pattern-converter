# 导出规范

## 文件命名规则

```
哆啦拼豆图纸_品牌名_宽x高_日期.扩展名
```

示例：

```
哆啦拼豆图纸_MARD_52x52_2026-06-03.png
哆啦拼豆图纸_COCO_104x104_2026-06-03.pdf
哆啦拼豆图纸_漫漫_52x52_2026-06-03.xlsx
哆啦拼豆图纸_盼盼_78x78_2026-06-03.csv
```

## PNG 导出规则

- 导出图纸预览图（格子图或色号图）
- 分辨率：每格 20px（可配置）
- 包含网格线
- 可选是否包含水印
- 使用 Canvas.toDataURL('image/png')

## PDF 导出规则

- 包含图纸预览图
- 包含色号统计表
- 包含品牌名、尺寸、成品尺寸信息
- 包含水印
- 使用 jsPDF（TODO）

## Excel 字段

| 列名 | 说明 |
|------|------|
| 行号 | 从 1 开始 |
| 列号 | 从 1 开始 |
| 色号 | 品牌色号代码 |
| 颜色名 | 颜色中文名 |
| HEX | 十六进制颜色值 |

汇总 Sheet：

| 列名 | 说明 |
|------|------|
| 色号 | 品牌色号代码 |
| 颜色名 | 颜色中文名 |
| 实际用量（颗） | 精确数量 |
| 建议备货量（颗） | 含 5% 损耗 |

## CSV 字段

与 Excel 汇总 Sheet 格式相同，UTF-8 BOM 编码。

## 水印规则

- 水印内容：哆啦拼豆图纸库
- 水印位置：右下角
- 水印颜色：半透明灰色
