# 会员制和 AI 积分方案

## 用户分层

### 1. 免费用户（Free）

**权益：**
- ✅ 上传图片、生成图纸（无限）
- ✅ 本地基础去背景（无 AI 调用）
- ✅ 编辑图纸（全功能编辑器）
- ✅ 导出 PNG（标准质量，有水印）
- ❌ PDF / SVG / CSV 导出
- ❌ AI 优化（扁平插画、Q版、治愈风、油画风）
- ❌ 高清超分
- ❌ 保存多个版本
- ❌ 分享到社区（需升级）

**访问限制：**
- 每个账户最多保留 20 个项目
- 每个月最多导出 10 次 PNG
- 30 天不活动则清理草稿

**获取方式：** 兑换码（邀请制）

**权益：**

- ✅ 扁平插画风（月 5 次）
- ✅ Q版卡通风（月 3 次）

- ✅ 导出 PDF（月 5 次）
- ✅ 保存最多 10 个版本
- ✅ 去水印
- ✅ 优先客服支持

**订阅期限：** 3 个月（自兑换码激活之日起）

**定价：** 免费（邀请码）

**续费：** 内测期间不需要续费，期满可升级到正式会员

## 兑换码内测方案

### 兑换码生成

```javascript
格式：DORA-YYYY-XXXX-XXXX
示例：DORA-2024-ALPHA-001

参数：
- 批次：ALPHA（第一批内测）
- 序列号：001-999
- 权益类型：Test（3个月内测会员）
- 数量：500 码（第一批）
```

### 兑换流程

1. 用户在登录后进入"会员"页面
2. 输入兑换码
3. 校验码有效性（未过期、未用尽、格式正确）
4. 激活 Test 会员权益（3 个月）
5. 显示过期时间和剩余次数

### 发放渠道

- 官方微博、微信公众号
- 小红书、抖音、B站 创意投稿
- 核心用户邀请链接（推荐制）
- 社群运营（QQ / 微信群）

### 兑换码核心规则

```javascript
{
  code: "DORA-2024-ALPHA-001",
  rewardType: "membership",
  rewardValue: {
    tier: "test",
    daysValid: 90,
  },
  maxRedeems: 1,              // 每个码全网最多用 1 次
  currentRedeems: 0,
  createdAt: 1704067200000,
  expiresAt: 1735689600000,   // 2025-01-01 过期
  usageLimit: "one-per-user",  // 每个用户只能用一个兑换码
}
```

## 订阅管理

### 自动续费

- 订阅到期前 7 天提醒
- 支持按月 / 按年自动续费
- 随时可取消自动续费
- 取消后可手动续费

### 订阅暂停

- 用户可暂停订阅最多 3 个月
- 暂停期间保留会员等级和未用次数
- 恢复时续费周期重新计算

### 退款政策

- 订阅后 7 天内无条件退款
- 之后仅退回未使用的次数折扣
- 内测会员（兑换码）不支持退款

## 数据实现

### 用户会员记录

```typescript
interface UserMembership {
  id: string
  userId: string
  tier: 'free' | 'test' | 'basic' | 'pro' | 'enterprise'
  planId: string                    // 计划 ID
  startDate: number                 // 生效时间
  endDate: number                   // 失效时间
  autoRenew: boolean                // 是否自动续费
  isActive: boolean                 // 是否当前生效
  source: 'redeem' | 'payment'      // 来源：兑换码或支付
  relatedOrderId?: string           // 关联的订单 ID
}
```

### 次数配额

```typescript
interface AiQuota {
  userId: string
  tier: string
  monthlyLimit: number              // 月度总配额
  used: number                      // 本月已用
  resetAt: number                   // 重置时间
  overagePaid: number               // 超额付费次数
}
```

### 使用日志

```typescript
interface UsageLog {
  id: string
  userId: string
  taskType: string                  // 功能类型
  costCredit: number                // 消耗的积分
  timestamp: number
  metadata?: {
    projectId?: string
    sourceOfCredit?: 'monthly' | 'package' | 'paid'
  }
}
```
