# AI 服务商调研报告

## 当前可选服务商

### 1. 腾讯混元生图 API

**优点**：
- 国内服务，延迟低
- 支持图片输入和编辑
- 与腾讯云生态集成
- 适合中文用户
- 支持快速迭代

**缺点**：
- 需要腾讯云账户
- API 文档相对不完整

**适合场景**：
- 国内用户优先
- 腾讯云部署
- 图片编辑和优化

**接入复杂度**：⭐⭐⭐（中等）

---

### 2. 火山引擎 Seedream

**优点**：
- 国内服务，质量较好
- 支持多种输入方式
- API 相对清晰
- 字节跳动体系

**缺点**：
- 需要字节账户
- 社区资源少

**适合场景**：
- 图像质量优先
- 国内部署
- 字节跳动生态

**接入复杂度**：⭐⭐⭐（中等）

---

### 3. 阿里云通义万相

**优点**：
- 国内服务
- 阿里云生态
- 文档较完整
- 支持多种图像处理

**缺点**：
- 费用相对较高
- API 调用限制

**适合场景**：
- 已在阿里云的用户
- 需要多种图像处理
- 企业级需求

**接入复杂度**：⭐⭐⭐⭐（较复杂）

---

### 4. OpenAI Images API

**优点**：
- 国际标准
- 图像质量最好
- 社区资源丰富
- API 文档详尽

**缺点**：
- 需要国际信用卡
- 国内访问需要代理
- 不适合国内用户

**适合场景**：
- 国际用户优先
- 图像质量最优
- 技术方案演示

**接入复杂度**：⭐⭐（简单）

## 本项目推荐方案

### 短期（v0.7.2-v0.8.0）

**推荐：腾讯混元 + 后端代理**

**理由**：
- 项目将部署到腾讯云，腾讯混元最佳匹配
- API 相对简单，易于接入
- 国内用户延迟最低
- 易于与腾讯云数据库集成

**架构**：
```
前端 → Node.js 后端代理 → 腾讯混元 API
```

---

### 中期（v0.9.0+）

**考虑多服务商支持**：
- 通过环境变量切换服务商
- 前端无需改动，只改配置

**实现**：
```ts
// server/services/providers/
// ├── tencentHunyuanProvider.ts
// ├── volcengineProvider.ts
// └── aliyunProvider.ts
```

---

### 长期（v1.0.0+）

**可选方向**：
- 如果国际用户多，集成 OpenAI
- 如果需要成本优化，支持多服务商自动降级
- 如果需要定制化，开发私有 AI 模型

## 结论

本项目**不绑定单一服务商**。

通过 adapter 模式和环境变量，可以：
1. 开发时用 mock，验证流程
2. 内测时用腾讯混元，测试质量
3. 后续轻松切换到其他服务商

这样既保证了灵活性，也降低了技术债。
