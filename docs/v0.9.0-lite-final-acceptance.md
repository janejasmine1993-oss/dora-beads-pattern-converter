## 🎯 版本定位和限制

### 定位

**v0.9.0-lite** 是一个**零成本、无后端、无数据库的会员体验版**，目的是：
- ✅ 快速验证产品市场需求
- ✅ 以最低成本维持服务可用性
- ✅ 支持小规模会员（共享口令）
- ✅ 为后续完整版本预留升级路径

### 已知限制

#### 无后端服务
- ❌ 无用户账户系统（不支持多人账户）
- ❌ 无用户认证和登录（只有口令验证）
- ❌ 无数据同步功能（无云端备份）
- ❌ 无实时通知或消息推送

#### 无数据库
- ❌ 作品仅本地保存（localStorage，浏览器特定）
- ❌ 作品丢失风险（用户清除缓存会丢失）
- ❌ 无版本历史或修订记录
- ❌ 无跨设备同步（作品仅当前浏览器可见）
- ❌ 无自动备份机制

#### 会员管理限制
- ❌ 所有用户共享同一口令（非独立账户）
- ❌ 无个人会员信息
- ❌ 无计费或续费管理
- ❌ 无分级会员（无 VIP、普通、免费 等区分）

#### AI 功能限制
- ❌ AI 优化处于 Mock 模式（演示结果，非真实）
- ❌ 无 AI 配额管理
- ❌ 无 AI 计费统计

#### 不适合场景

| 场景 | 原因 |
|------|------|
| **大规模付费会员** | 无独立账户和计费系统 |
| **企业级协作** | 无用户管理和权限控制 |
| **数据安全敏感** | 无加密和后端保护 |
| **跨设备同步** | 无云端存储和同步 |
| **长期数据存储** | localStorage 无保证 |

### 升级路径

若需恢复完整功能，参考 [docs/rollback-v0.9.0-lite.md](rollback-v0.9.0-lite.md)：

1. **恢复数据库**：启用 PostgreSQL
2. **部署后端**：部署 CloudBase 云托管服务
3. **启用认证**：切换 VITE_LITE_MODE=false
4. **重新部署**：npm run build → tcb deploy

## 🔐 生产环境配置

### 当前环境变量（.env.production）

```bash
# LITE_MODE 启用
VITE_LITE_MODE=true

# 会员口令（当前为测试口令，生产前需修改）
VITE_MEMBER_ACCESS_CODE=member2024

# 口令版本号（每月更新时递增）
VITE_ACCESS_CODE_VERSION=2026-06

# API 和认证（LITE_MODE 下不使用）
VITE_API_BASE_URL=/api
VITE_AUTH_MODE=real

# AI 配置（LITE_MODE 下使用 Mock）
VITE_AI_RUNTIME_MODE=mock
VITE_AI_PROVIDER=mock
```

### 修改生产口令

每月/每期修改会员口令时：

1. **编辑 .env.production**
   ```bash
   VITE_MEMBER_ACCESS_CODE=<新口令>
   VITE_ACCESS_CODE_VERSION=2026-07  # 同时更新月份
   ```

2. **提交并推送**
   ```bash
   git add .env.production
   git commit -m "chore: update member access code for July 2026"
   git push origin main
   ```

3. **Cloudflare 自动重新部署**
   - 用户旧授权自动失效
   - 需要重新输入新口令
